WAITWISE
Intelligent Dynamic Queue & Token Management System
============================================================

1. PROJECT OVERVIEW
------------------------------------------------------------

WaitWise is an intelligent digital queue and token management
system designed to reduce physical waiting lines and improve
the customer experience.

Instead of standing in a long queue, users can register,
generate a digital token, monitor their queue position, and
receive an estimated waiting time.

The system also provides administrators with tools to manage
queues, counters, users, and token status in real time.


2. PROBLEM STATEMENT
------------------------------------------------------------

Traditional queue systems require people to physically stand
in lines. This can result in:

- Long waiting times
- Crowded waiting areas
- Lack of information about queue position
- Poor queue management
- Unpredictable waiting time
- Manual work for staff
- Customer dissatisfaction

WaitWise solves these problems using a digital queue system.


3. PROPOSED SOLUTION
------------------------------------------------------------

WaitWise provides a centralized digital platform where:

1. Users create an account.
2. Users browse available queues.
3. Users select a service.
4. Users generate a digital token.
5. The system assigns a token number.
6. Users can monitor their queue position.
7. The system calculates estimated waiting time.
8. Staff can call the next token.
9. Queue status is updated in real time.
10. Administrators can manage the entire system.

8. AI CONFIGURATION
------------------------------------------------------------

WaitWise is currently configured to use Ollama locally.

Example configuration:

OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=gemma3:1b
AI_PROVIDER=ollama

Ollama must be running on the local machine.

The installed model is:

gemma3:1b


9. HOW TO RUN THE PROJECT
------------------------------------------------------------

STEP 1:
Open PowerShell in the WaitWise project directory.

STEP 2:
Activate the virtual environment:

.\venv\Scripts\Activate.ps1

STEP 3:
Install dependencies:

pip install -r requirements.txt

STEP 4:
Check Ollama:

ollama list

STEP 5:
Run the AI model:

ollama run gemma3:1b

STEP 6:
Exit Ollama:

/bye

STEP 7:
Initialize the database:

python seed.py

STEP 8:
Start WaitWise:

python run.py

STEP 9:
Open the application in a browser:

http://127.0.0.1:5000
